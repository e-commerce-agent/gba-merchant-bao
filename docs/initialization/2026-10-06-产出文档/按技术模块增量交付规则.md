# 按技术模块增量交付规则

基础 change 只交付包结构、依赖治理、Flyway、租户夹具、Springdoc、日志和测试底座。后续模块按下表触发依赖和中间件：

| 模块 | 触发时才加入 | 必须同时交付 |
| --- | --- | --- |
| 登录/认证 | Redis starter、会话 key、认证表和认证配置 | 登录接口、认证日志、Redis/集成测试、OpenAPI 快照和回退证据 |
| 商品/库存/订单 | 对应表、Mapper 和真实业务依赖 | 租户 schema、状态/金额规则、接口契约、跨租户测试 |
| 文档任务 | RabbitMQ | 任务状态表、重试/降级、202/statusUrl 契约和消息测试 |
| RAG/Agent 亮点 | Milvus、LangChain4j 或 Redis ChatMemory | 领域 Service、Tool 安全、SSE 事件、日志和本亮点独立评测 |

不得因为未来规划预装 RabbitMQ、Milvus 或 LangChain4j。四个 Agent 亮点在基础模块完成后分别开始，互不等待；每个亮点完成即进行自己的真实量化和评测，不把评测结果合并到基础 change。
